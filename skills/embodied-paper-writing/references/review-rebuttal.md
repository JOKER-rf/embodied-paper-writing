# 投稿前审查、Rebuttal 与期刊返修

## 审查输出要可行动

先识别影响技术有效性的实质问题，再处理表达和格式。每个问题给出稿件位置、相关论点、证据/推理、影响与最小可行修复；不把个人措辞偏好写成接收障碍。

| 类型 | 典型问题 | 应给的修复 |
| --- | --- | --- |
| 确定错误 | 摘要与表格数值冲突、公式单位错误、数据划分泄漏 | 指定依据和需要修正的位置 |
| 证据缺口 | 跨对象主张没有隔离划分，机制结论缺对照 | 补充检验或收窄主张 |
| 可复现性缺口 | 动作坐标、延迟、干预统计不明 | 补协议与真实配置 |
| 定位与表达 | 最近邻差异模糊、结论重复 | 重写段落并解释主线变化 |
| 投稿规则 | 模板、匿名、篇幅、声明未符合当期要求 | 关联官方来源与适用阶段 |

每条区分“已核实”与“怀疑但需材料确认”。材料不够时提出精确待核验项，不能凭空判定方法无效。不估计录用概率，也不虚构程序委员会评分。

## 内容审查顺序

1. 摘要和贡献是否只覆盖真正完成的工作；最强形容词能否找到证据。
2. 问题定义是否自洽；算法、公式、代码和信息流是否相符。
3. 最接近工作是否被准确引用与比较；新颖性是否是实质差异。
4. 数据划分、对照预算和闭环协议能否支撑结果解释。
5. 不确定性、失败、限制和复现信息是否足够。
6. 当期模板、匿名、声明、引用和提交文件要求是否核验。

用论点与证据表追踪修复。用户要求审查时先交付问题清单；用户要求直接修改时，在授权范围内修正能确认的问题，别只建议作者自行修改。

## 回复前先核对规则

目标会刊、年份、track 和阶段决定字数/页数、每位 reviewer 的限制、是否可加图、新实验、外部链接、上传修订稿及截止时间。按 [venues.md](venues.md) 查当期官方政策；规则未知时先形成内容草稿，别宣称可直接提交。

## 逐条回应矩阵

```text
问题 ID：R2-Q1
审稿意见：原文或准确摘录（不改变意思）
问题类别：技术错误 / 协议不清 / 新颖性 / 证据不足 / 表达
作者判断：同意 / 部分同意 / 依据原稿澄清
支持材料：原稿位置、已有结果、已完成新增实验
需要修改：具体段落/图表及真实修改状态
回复结论：能解决什么、仍存在什么限制
状态：已有证据 / 已完成补充 / 计划 / 无法完成
```

先覆盖可能改变技术判断的问题，再合并共同疑问和次要勘误。引用 reviewer 的标识而非猜测其身份。不同 reviewer 的答复不能相互冲突。

## 回复的写法

通常采用“直接回答 → 证据与条件 → 修改位置 → 必要边界”。感谢一次即可，避免大段礼貌套话。对误解先补充读者缺少的信息，不用对抗性语言指责其阅读。

- **有原稿证据**：给准确章节/表图，解释为何它回答问题；若表达确实不清，补上拟议改句。
- **完成了新实验**：给协议、真实结果、样本/预算和改变了哪条判断；不能只写“进一步验证”。
- **审稿意见成立**：承认具体问题并修正，说明这是否影响核心结论。
- **尚未做实验**：明确目前不能支持的部分，使用计划或限制语态；不能写 “We have conducted”。
- **无法完成新要求**：说明现有证据可回答的范围，收窄不成立的主张；不要无依据声称该要求无关。

英文段落骨架：

```text
Regarding [specific concern], [direct answer within the evidence scope].
[Evidence, protocol and exact manuscript location].
[Actual revision / proposed clarification, with status made explicit].
[Remaining limitation, when material to the concern].
```

不要将 `[actual revision]` 替换为尚未落盘的修改；草稿中的拟议修改应使用拟议措辞。

## 期刊返修

逐条保留 editor/reviewer 的意见编号，记录“已修改 / 解释后保持 / 部分完成”。回复中的页码行号使用修订稿实际位置；排版未定时用章节和表图标识，不编造行号。

按当期要求准备 response letter、修订稿和标注改动稿；不默认所有期刊接受相同 diff 格式。已有会议版本时，准确说明实质新增内容并核对重叠发表政策，不能按一个通用百分比声称满足要求。

## 最后核对

逐条意见都有回应；每个新数字可追溯；“已修改”与文件一致；回复和稿件主张一致；限制与匿名规则对应当期要求。交付可编辑回复和仍需作者处理的事项，不代为上传或发送。
