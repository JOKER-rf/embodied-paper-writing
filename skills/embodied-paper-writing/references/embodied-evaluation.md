# 具身智能论文的证据与评测

把本指南作为按主张选择的检查菜单。并非每篇工作都需要真机、多本体或所有泛化实验；要求的是结论范围与实际证据相称。对不适用项目写明理由，不凭空扩大实验规模。

## 任务、系统与数据必须说清什么

| 维度 | 至少需要交代的内容 | 容易造成的误判 |
| --- | --- | --- |
| 任务 | 初始状态、目标、终止、时间/步数预算、成功与部分成功判据 | 用主观演示代替可复查成功判定 |
| 观测 | 相机/深度/触觉/本体传感、分辨率、历史窗口、标定与时间同步 | 测试使用训练专属真值或未来信息 |
| 动作 | 关节/末端/速度/力、绝对或增量、坐标、单位、夹爪、归一化 | 不同动作空间下的结果被当成算法差异 |
| 控制 | 策略频率、底层控制频率、动作块、重规划、延迟、插值与限幅 | 忽略下游控制器对成功的贡献 |
| 平台 | 机器人/夹爪、自由度、传感器、仿真器与版本、计算硬件 | 单平台结果被扩大为跨本体能力 |
| 数据 | 轨迹/片段/帧数、任务/对象数、采集方式、失败样本、预训练来源 | 用帧数冒充独立示范数 |
| 训练 | 数据混合、模型初始化、可训练模块、超参数、种子与预算 | 更多数据/计算被写成结构改进 |
| 部署 | 是否联网、外部规划器/LLM、地图、人工指令、重置及接管 | 人工辅助被隐藏在“自主”结果里 |

只写确实掌握的信息；缺失项进入作者待办，不能由机器人型号或常识推断出实验配置。

## 划分与泄漏

先定义独立数据单位，再划分训练、验证与测试：轨迹、对象实例、场景、采集会话和平台通常比单帧更接近真实单位。不要将同一轨迹的相邻帧随机分到训练和测试。

区分对象实例、对象类别、场景、语言表述、任务组合、动力学、本体等泛化轴。说明训练/测试重叠、外部预训练可见性以及未知之处；“未在微调数据中出现”不等于“基础模型从未见过”。

测试集不用于调超参数或挑检查点。若已有此类选择，透明说明并另设评估或收窄结论，不能事后称为独立测试。数据增强不应跨越划分边界复制原始样本。

跨本体需区分：相同机器人不同实例、不同机械臂、不同自由度、不同动作接口。泛化标签与实际变化一致。

## 公平对照与消融

报告匹配了哪些因素：训练数据、预训练权重、模型容量、训练计算、调参预算、测试工具、控制频率、动作空间和部署硬件。无法完全匹配时提供受控子比较并说明剩余差异，不用一句“公平比较”代替协议。

最近邻基线、简单强基线、关键模块消融和预算匹配对照按论文主张选择。复用已发表数值时标明其来源与协议差异；只有协议可比的数值才能支持直接排名。

删除一个模块若同时减少参数量、训练信号和计算，不能唯一定位机制。可考虑等参数替代、打乱/屏蔽特定信号、固定数据的替代损失，或独立控制候选原因；不必为每个模块机械运行所有组合。

诊断分析应有竞争解释与可否定条件。注意力热图、嵌入聚类和个别轨迹通常是辅助证据，不能单独证明物理理解或因果机制。

## 成功率、重复与统计

- 记录每条件成功数/总尝试数、独立训练种子、每种子的测试 episode，以及任务/对象/会话的层级。大量相关帧不能作为大量独立样本。
- 区分不同训练种子的训练变异、固定策略重复执行的环境变异和对象/任务抽样变异。只做一个训练种子时如实记录。
- 明确宏平均（先按任务求均值）与微平均（汇总全部试次）的区别；任务试次数不等时二者不能混用。给出每任务结果以便检查聚合是否掩盖退化。
- 报告标准差、标准误或置信区间时写出定义、置信水平、重复单位和估计方法。二项成功率可在假设适合时使用 Wilson 区间；分层数据按对应层级估计不确定性，不能把相关试次当独立伯努利试验。
- 配对任务/场景比较尽量保留配对结构；选择检验前确认独立性与样本结构。多次比较或探索性分析应透明说明，不挑有利检验。
- 绝对百分点差为 `100 × (p_new - p_base)`；相对提升为 `100 × (p_new - p_base) / p_base`，后者在基线为零时不定义。原始比例与百分比单位须一致。
- 样本有限、区间很宽或未做统计检验时报告实际差异与不确定性，不写“显著优于”。统计不显著也不等于已证明等效。
- 不预设适用于所有机器人的试验次数或种子数。按变异、效应、资源和主张说明选择理由；无法增加重复时缩小结论。

## 闭环、干预与真实机器人

离线预测损失、视频生成质量和闭环任务成功回答不同问题。若主张控制性能，需要相应交互评估；仅离线证据应保持离线结论。

预先说明首次尝试、重试、人工纠正、人工任务分段、急停、自动恢复、设备异常的计数规则。自主完成与人工辅助完成分别报告，不能静默删除失败或把最佳重试计为一次成功。

硬件异常排除需要理由和可追溯记录，并给出尝试总数与排除数。策略导致的碰撞、超时和抓取失败属于性能信息；外部设备故障与算法失败要分别描述。

视频说明播放速度、是否剪辑、是否选例及干预位置。精选视频可展示能力边界和机制，不能替代完整统计。涉及用户数据或人类参与时只记录真实的同意与审批状态。

真机和模拟分开列协议与结果。Sim-to-real 主张说明真实数据是否参与训练、调参、标定或测试。Zero-shot 必须明确“未使用哪种目标域适配数据”，不能隐藏手工调参。

## 不同研究方向的特别证据

### VLA 与机器人基础模型

说明视觉/语言/动作接口、预训练和微调数据、机器人数据混合、动作 tokenizer 或连续动作头、冻结模块、动作块与推理循环。区分语言理解、视觉识别、动作生成和下游控制带来的效果。

组合泛化要控制对象、任务和指令重叠；只改写句式不自动等于新任务。跨平台比较需报告适配器与各平台数据量。不得以底座模型规模证明“具身理解”。

### 世界模型与规划

区分重建/生成质量、动作条件动力学预测、长时域滚动误差、可规划性和闭环收益。若声称动作可控，至少考虑固定初始条件改变动作的对照；若声称帮助规划，与计算预算匹配的无模型/其他规划器比较。

报告预测时域、规划时域、候选数量、重规划频率、约束与奖励来源。图像更逼真不必然使规划更好；不能将 PSNR 等离线指标直接等同控制收益。

### 操作、接触与灵巧控制

说明物体几何/材质、接触阶段、摩擦或扰动、姿态/力误差、掉落与恢复；主张安全时给出所测风险指标和范围，碰撞较少不能推出普遍安全。

### 导航与长期交互

交代地图、定位、目标可见性、轨迹预算、碰撞规则、记忆重置。成功率与路径/时间效率分开报告。长时程主张需明确子任务数量、依赖关系和错误累积，不能只延长视频时长。

### 基准、数据集和理论工作

基准检查任务采样、标注一致性、难度覆盖、指标效度、泄漏、许可证及基线复现。理论工作说明假设与机器人场景的映射，纯理论不强制真机实验；数据论文也不强制提出新控制算法。

## 论点到证据的映射

| 候选论点 | 需要什么证据 | 仍不足以支持什么 |
| --- | --- | --- |
| 提高指定任务成功率 | 同协议对照、分母与重复、误差定义 | 开放世界泛化 |
| 改善某个未见分布 | 该轴的隔离划分、预训练可见性说明 | 其他泛化轴 |
| 模块处理遮挡/延迟 | 独立控制干扰和替代解释 | 唯一根因或通用因果结论 |
| 更高效 | 指定硬件/批量/分辨率下的延迟、显存、调用与总成本 | 所有设备上都更快 |
| 支持真实部署 | 真机协议、干预/失败、完整运行统计 | 用户收益和长期可靠性 |
| 更统一 | 明确共享部分、跨任务/平台结果与负迁移 | 所有本体和任务通用 |

对每个核心实验写清：若结果没有改善或出现反例，应该撤回/收窄哪条主张。这样实验才真正检验论文，而非只为论点作展示。
