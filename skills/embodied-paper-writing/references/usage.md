# 使用说明

## 调用与安装

本技能目录名为 `embodied-paper-writing`，入口为 `SKILL.md`。在已加载该技能的 Codex 会话中，输入 `$embodied-paper-writing` 或通过技能选择器选择它。也可用自然语言说明要撰写具身智能论文，由环境进行技能匹配。

个人使用时，将整个技能目录放到客户端支持的技能发现位置；当前官方说明列出的个人目录为 `~/.agents/skills/`，项目目录为 `.agents/skills/`。若桌面环境已通过 `$CODEX_HOME/skills/` 或 `~/.codex/skills/` 管理个人技能，可沿用其已识别的位置。以客户端版本为准，不要在多个扫描位置重复安装同名技能。保留 `agents/`、`references/`、`assets/` 的相对位置；若新技能未显示，重新加载或重启客户端。参见 [OpenAI 官方文档](https://learn.chatgpt.com/docs/build-skills)。

暂不安装也能使用：在可访问该目录的会话中，提供 `SKILL.md` 的绝对路径，要求按其说明执行。本技能没有专用 MCP 服务或 Python 包依赖；联网文献核验、数据分析、LaTeX 编译依赖当前环境提供的工具。

## 最小输入

至少提供研究想法、方法说明或现有稿件中的一项，并说明本次任务。推荐同时提供：

| 信息 | 示例 | 缺少时的处理 |
| --- | --- | --- |
| 目标会刊与年份、track | CVPR 2027 主会 / T-RO regular | 可先写内容；投稿规则保持未核验 |
| 研究对象与任务 | 双臂操作、视觉导航、VLA、世界模型 | 从材料提取，不擅自替换研究主题 |
| 当前阶段 | 想法 / 部分结果 / 初稿 / 返修 | 从证据成熟度选择模式 |
| 方法与最近邻工作 | 方法笔记、代码片段、论文链接 | 核验前不宣称首创 |
| 结果与协议 | 日志、CSV、配置、成功判据 | 可交付草稿和实验方案，不能补造数值 |
| 本次产物 | 摘要、全文、消融设计、rebuttal | 完成相应部分 |
| 语言与格式 | 中文讨论，英文 LaTeX 正文 | 默认中文讨论、英文 Markdown 正文 |

可复制 [研究简报模板](../assets/paper-brief.md)。已有材料足够时，无需重新填写。

## 七种模式与提示词

### 1. 从想法到论文主线

```text
使用 $embodied-paper-writing，做论文构思。
方向：长时程机器人操作；目标：ICLR，年份待定。
我观察到：加入历史图像后，某些任务更好，但换对象时仍失败。
材料：./notes/idea.md。
请提出可区分的研究假设，选择适合当前证据的叙事主线，
给出一句话主张、最近邻比较维度、可否定主张的实验和论文提纲。
明确哪些是已有事实，哪些只是待检验假设。
```

预期产物：研究定位卡、论点与证据表、优先实验。没有数据时，不生成假装完成的结果段。

### 2. 从材料撰写初稿或单节

```text
使用 $embodied-paper-writing，撰写英文 Introduction 和 Method。
目标：CoRL；年份与 track 在 ./brief.md 中。
材料：./notes/method.md、./results/summary.csv、./results/protocol.md。
直接输出可编辑正文到 ./paper/draft.md。
不支持的结果标为待补；引用只使用已核验条目。
正文外附论点与实验对应关系，以及仍需作者补充的信息。
```

全文也采用此输入方式；指定已有 `.tex` 主文件可延续工程。不要假设任意代码仓库已有全部论文实验。

### 3. 重构或局部改稿

```text
使用 $embodied-paper-writing，重构 ./paper/intro.tex。
保留已有技术事实、结果数值、引用键与符号。
把“模块清单”改写成“问题—机制—设计”的论证链，压缩重复背景。
直接修改文件；另列实质性主张变化。不要改动其他章节。
```

预期产物：修订文本和必要的主张风险说明。若只需语言润色，不额外启动选题与实验设计。

### 4. 实验与消融补强

```text
使用 $embodied-paper-writing，审查实验设计。
材料：./paper/draft.md、./results/protocol.md。
核心主张：改善未见对象的闭环操作，额外训练预算有限。
逐项检查划分泄漏、对照公平性、干预/重试统计和不确定性。
按“会改变核心结论 / 增强解释 / 可选展示”排序给出补实验方案，
每项写清待检验主张、对照、控制变量、指标和否定条件。
```

预期产物是实验方案；不自动启动训练、消耗 GPU 或操作真实机器人。

### 5. 投稿前审查

```text
使用 $embodied-paper-writing，对 ./paper/main.tex 做投稿前审查。
目标：ICML，具体年份见简报；实验材料在 ./results/。
核对当年官方要求、主要论点的证据及数值口径，
给出有稿件位置和可执行修复方式的问题清单。
把确定错误、证据不足和写作建议分开；不要猜测录用概率。
```

预期产物：有位置、证据与修复建议的审查报告。模拟审稿不冒充真实程序委员会意见。

### 6. Rebuttal 与期刊返修

```text
使用 $embodied-paper-writing，为 ./reviews/reviews.md 撰写英文回复。
原稿：./paper/submitted.pdf；已完成补充结果：./results/new_results.md。
目标会刊、回复限制和当前阶段见 ./reviews/constraints.md。
先建立逐条问题—证据—修改位置矩阵，再写可提交的回复草稿。
不要把计划实验写成已完成实验，不承诺尚未批准的新增工作。
```

期刊返修可另要求 response letter、修订稿和改动清单；具体是否需要 diff、cover letter 依当期政策核验。

### 7. 会刊适配与转投

```text
使用 $embodied-paper-writing，将现有稿件适配到 T-RO。
材料：./paper/draft.tex、./paper/prior_publications.md。
核对当前作者指南，给出贡献定位、主文结构、扩展证据和格式修改，
已有会议版本与本稿的重叠内容要明确列出。
完成本地可审阅稿件，不进行投稿或联系编辑。
```

转投需重审读者、贡献匹配与证据成熟度，不能通过更换措辞掩盖重叠发表。

## 输出怎样检查

完整任务通常应得到请求的正文，以及简短的核心主张、来源与证据状态、重大缺口、引用和投稿规则核验状态。局部任务只附与本次修改有关的说明。

检查四点：结果是否能追溯到材料；最强主张是否被当前实验覆盖；图表是否有分母、单位和不确定性口径；官方规则是否对应正确年份、track 和阶段。

## 常见情况

- **只有想法**：先构思和设计实验；不以“没有数据”为由停止所有工作，也不写成完整研究成果。
- **只有汇总表**：可保留作者报告的数值，但成功判据、试验次数和聚合方式仍待核验。
- **只有模拟实验**：写模拟条件下的发现；真实部署价值可作动机，不能写成已验证结论。
- **无法联网**：继续基于已有材料写作，标记文献与规则未核验，不编造 BibTeX。
- **需要英文润色**：明确“仅语言修改”，保留事实强度、技术术语和引用。
- **希望冲击顶会**：先定位可检验贡献和关键证据；本技能不能保证任何接收或奖项结果。
